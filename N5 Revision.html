1. Software Design & Development

This unit focuses on programming concepts, the software development process, and writing code (typically Python or Visual Basic).

The Iterative Development Process

  • Analysis: Identifying functional requirements (inputs, processes, outputs) and assumptions.
  • Design: Planning the solution using pseudocode, structure diagrams, or flowcharts.
  • Implementation: Writing the code.
  • Testing: Ensuring the code works (Normal, Extreme, and Exceptional data).
  • Evaluation: Checking fitness for purpose, efficiency, robustness, and readability.

Key Data Types

You must select the correct data type for variables:

  • String: Text (e.g., "Scotland")
  • Integer: Whole numbers (e.g., 15)
  • Real: Decimal numbers (e.g., 3.14)
  • Boolean: True/False
  • Char: Single character (e.g., 'A')
  • 1D Array: A list of data of the same type.

Standard Algorithms

You need to be able to read and write these from memory:

  • Input Validation: Ensuring data is within acceptable limits (using a While loop).
  • Running Total: Adding a value to a total inside a loop.
  • Traversing an Array: Using a fixed loop to move through every item in a list.

2. Computer Systems

Understanding how computers store data and the hardware inside them.

Data Representation

  • Binary: Storing integers using 1s and 0s.
  • Floating Point: Used for real numbers. Stored as Mantissa (precision) and Exponent (range).
  • Extended ASCII: 8-bit code to represent text characters (256 possible characters).
  • Vector Graphics: Stored as descriptions of shapes (attributes: coordinates, fill colour, line colour). scalable without losing quality.
  • Bit-mapped Graphics: Stored as a grid of pixels. Quality depends on resolution and colour depth.

Computer Structure

  • CPU: The brain. Contains the ALU (Arithmetic Logic Unit), Control Unit, and Registers.
  • Buses:
    • Data Bus: Carries data (bi-directional).
    • Address Bus: Carries memory location address (uni-directional).

Security & Environment

  • Firewall: Filters incoming/outgoing network traffic.
  • Encryption: Scrambling data so it is unreadable without a key.
  • GDPR: Law controlling how personal data is processed.
  • Environmental Impact: Energy consumption, e-waste, monitor sleep settings.

3. Database Design & Development

Creating and managing relational databases.

Analysis & Design

  • Entities & Attributes: The object (e.g., Customer) and its details (Name, Address).
  • Primary Key: A unique identifier for a record.
  • Foreign Key: A field used to link two tables together.
  • Validation Checks: Presence check, Restricted choice, Field length, Range check.

SQL (Structured Query Language)

You must be able to write SQL queries:

SELECT surname, town
FROM Customer
WHERE age > 18 AND town = 'Aberdeen'
ORDER BY surname ASC;

Note: Know how to use INSERT, UPDATE, and DELETE commands as well.

4. Web Design & Development

Building websites using HTML, CSS, and JavaScript.

Languages

  • HTML (Structure): Defines the content (headings, paragraphs, images, links).
    Tags: <h1>, <p>, <div>, <a href="...">, <img src="...">.
  • CSS (Style): Defines the look (colour, font, layout). Can be Inline, Internal, or External.
    Selectors: Element (p {}), Class (.style {}), ID (#header {}).
  • JavaScript (Interactivity): Handles events like onmouseover or onclick.

Design Concepts

  • Wireframes: A visual blueprint of the page layout before coding.
  • Low-fidelity prototyping: Sketches/paper versions of the site.
  • File Formats:
    • Audio: WAV (high quality, large), MP3 (compressed).
    • Graphics: JPEG (photos, lossy), PNG (transparency, lossless), GIF (simple animation).
