1. Analysis & Design

Requirements

Before building a website, you must identify what it needs to do.

  • End-User Requirements: What the visitors of the site want to do (e.g., "Users should be able to view a video of the product").
  • Functional Requirements: What the website must technically do/contain (e.g., "The site must have a video player on the home page").

Design Techniques

  • Wireframes: A visual blueprint showing the structure of a page. It includes the layout of text, images, and navigation but usually lacks color or specific content.
  • Low-Fidelity Prototypes: Often paper-based sketches showing how a user navigates from page to page. It tests the flow of the site.

2. HTML Structure & Media

Hyperlinks

  • Internal Hyperlink: Links to a page within the same website.
    <a href="contact.html">Contact Us</a>
  • External Hyperlink: Links to a different website (requires full URL).
    <a href="https://www.google.com">Google</a>

Inserting Media

You must know the tags and attributes for inserting media.

Images (img)

<img src="cat.jpg" alt="A picture of a cat" width="300" height="200">

Audio (audio)

<audio controls>
  <source src="music.mp3" type="audio/mpeg">
</audio>

Video (video)

<video width="320" height="240" controls>
  <source src="movie.mp4" type="video/mp4">
</video>

3. CSS (Cascading Style Sheets)

CSS controls the presentation (fonts, colors, layout) of the web page.

Three Methods of Adding CSS

  1. Inline: Written directly inside the HTML tag. (Lowest priority)
    <p style="color: blue;">
  2. Internal: Written inside <style> tags within the <head>.
  3. External: Written in a separate .css file and linked. (Best practice)
    <link rel="stylesheet" href="styles.css">

Selectors: ID vs Class

Selector Type HTML Attribute CSS Symbol Usage
Element N/A None (e.g., p {}) Styles ALL elements of that type.
ID id="logo" Hashtag (e.g., #logo {}) Used for ONE unique element per page.
Class class="big-text" Dot (e.g., .big-text {}) Used for MANY elements that share a style.

Common Properties

body {
  font-family: Arial;
  background-color: lightgray;
}

.highlight {
  color: red;
  text-align: center;
  font-size: 16px;
}

4. JavaScript Interaction

JavaScript handles behaviour and interactivity. At N5, you deal with mouse events.

Common Events

  • onmouseover: Triggered when the mouse pointer hovers over an element.
  • onmouseout: Triggered when the mouse pointer leaves (moves out of) an element.
  • onclick: Triggered when the user clicks an element.

Common Tasks

1. Changing an Image (Rollover Effect)

<img src="pic1.jpg"
  onmouseover="this.src='pic2.jpg'"
  onmouseout="this.src='pic1.jpg'">

2. Changing CSS Styles

<h1 onclick="this.style.color='red'">Click me!</h1>

5. Testing & Evaluation

Testing

After building the site, you must check it works correctly.

  • Hyperlinks: Check all internal and external links go to the correct destination.
  • Media: Ensure images, audio, and video load and play correctly.
  • Consistency: Ensure fonts and colours are the same across all pages (usually handled by External CSS).

Evaluation

Reviewing the final product against the initial plan.

  • Fitness for Purpose: Does the website meet all the Functional Requirements?
  • User Interface: Is the navigation easy to understand? Is the layout consistent?
